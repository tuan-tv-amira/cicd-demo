Trang web này không có ai bấm nút "deploy" tay cả.

Mỗi khi có người thay đổi code và merge vào nhánh main, GitHub Actions tự động:

  1. Kiểm tra (CI) — chạy test để chắc chắn code không lỗi.
  2. Triển khai (CD) — nếu test pass, tự động đưa bản mới nhất lên chính trang bạn đang xem.

Xem chi tiết từng bước tại tab Actions của repo trên GitHub.
